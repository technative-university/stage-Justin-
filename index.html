01 · Basis

Variabelen

Een opslagplaats met een naam waarin je informatie bewaart.

Wat is het?

Een variabele is een soort opslagplaats waarin je informatie kunt bewaren. Je geeft deze opslagplaats een naam, zodat je de informatie later kunt gebruiken.

Hoe hebben wij dit gebruikt?

Bij onze rekenmachine gebruikten we variabelen om de getallen die de gebruiker invoert op te slaan.

getal_1 = 5
getal_2 = 10
# hierdoor wordt getal_1 opgeslagen als 5 en getal_2 als 10
02 · Basis

Datatypes

Datatypes geven aan wat voor soort waarde een variabele is.

🔢

Integer

Een heel getal, zonder decimalen.

getal_1 = 10

Voorbeeld: x = 10 is een integer.

📐

Float

Een getal met decimalen.

getal_2 = 10.5

Voorbeeld: y = 11.5 is een float.

📝

String

Tekst. Staat altijd tussen '' of "".

naam = 'jathan'

Voorbeeld: fruit = "apple" is een string.

📋

List

Een lijst waarin je meerdere waarden kunt opslaan.

getallen = [0, 3, 5, 1, 7]
# a[0] = 1  → eerste element

Voorbeeld: a = [1, 5] is een list.

Bij onze programma’s waren integers en floats vooral handig voor de rekenmachine, en strings voor teksten en invoer.

03 · Rekenen

Operators

Tekens waarmee je kunt rekenen of dingen kunt vergelijken.

+ Optellen

resultaat = 5 + 3  # 8

- Aftrekken

resultaat = 10 - 4  # 6

* Vermenigvuldigen

resultaat = 6 * 7  # 42

/ Delen

resultaat = 20 / 4  # 5.0

Bij onze rekenmachine hebben we operators veel gebruikt om berekeningen uit te voeren.

04 · Beslissingen

Conditional statements (if / else)

Met if en else kan de computer een beslissing maken.

Voorbeeld bij ons gokspel

if gok == geheim_getal:
    print('goed geraden')
else:
    print('fout')
05 · Herhalen

Loops (while & for)

Een loop zorgt ervoor dat een stukje code meerdere keren wordt uitgevoerd.

🔁

While-loop

Blijft doorgaan zolang een bepaalde voorwaarde waar is.

while gok != geheim_getal:
    gok = int(input('raad het getal: '))

Handig voor ons raadspel: je moet meestal vaker dan één keer raden.

🔢

For-loop

Gebruik je wanneer je iets een bepaald aantal keer wilt uitvoeren of door een lijst wilt gaan.

for getal in [1, 2, 3, 4, 5]:
    print(getal)

Of: for i in [1, 5, 7, 3]: print(i)

Comments, input, print, modules & indentation

6. Comments

Opmerkingen in je code die de computer niet uitvoert. Handig om uit te leggen wat er gebeurt.

# dit vraagt de gebruiker om een getal

7. Input

Met input kan de gebruiker iets invoeren.

naam = input('wat is je naam? ')
getal_1 = input('geef het eerste getal: ')

Bij de rekenmachine gebruikten we dit om de getallen van de gebruiker te krijgen.

🖥️

8. Print

Met print laat je iets zien op het scherm.

print('welkom bij de rekenmachine')

We gebruikten dit om antwoorden en uitslagen van spellen te tonen.

📦

9. Importing modules

Een module bevat code die je in je eigen programma kunt gebruiken. Met import haal je die binnen.

import random
geheim_getal = random.randint(1, 100)

Voor ons getallenspel gebruikten we de random-module om een willekeurig getal te kiezen.

⇥

10. Indentation

Inspringen is in Python heel belangrijk. Python ziet hiermee welke code bij elkaar hoort.

if getal > 10:
    print('het getal is groter dan 10')
# de inspringing na de : is de indentation

Als de indentation verkeerd is, werkt de hele code niet.

11 · Versiebeheer

Git

Een programma waarmee je de veranderingen in je code kunt bijhouden — een soort geschiedenis van je project.

In Git sla je alle codes op die je hebt gebruikt. Je kunt zien wat er veranderd is, terug naar eerdere versies gaan en veilig samenwerken zonder elkaars werk te overschrijven.

12 · Online platform

GitHub

Een online platform waar je Git-projecten kunt opslaan en delen.

Waarom GitHub?

  • Je code bewaren in de cloud
  • Vanaf een andere computer bij je code komen
  • Samenwerken aan één codebase
  • Codes met anderen delen

Verschil: Git houdt de geschiedenis van je code bij op je computer. GitHub is de plek waar je die Git-projecten online opslaat en deelt.

13 · Terminal

Basic Linux commands

Commando’s die je in de terminal (bijv. via Termius / Amazon Linux) gebruikt om bestanden en mappen te beheren.

ls

Laat zien welke bestanden en mappen zich in de huidige map bevinden.

cd

Verander van map (change directory).

mkdir

Maak een nieuwe map aan. Voorbeeld: mkdir python → map met de naam “python”.

touch

Maak een nieuw leeg bestand. Voorbeeld: touch rekenmachine.py.

Praktijkvoorbeeld: voorraad beheren

In een bedrijf kun je Python gebruiken om de voorraad te meten en automatisch actie te ondernemen. Simpel gezegd: 

voorraad = 500  # stuks

if voorraad < 150:
    print('er is weinig voorraad')

In een echt bedrijf

Het programma leest gegevens uit een database. Stel je begint met 500 producten. Als er 400 verkocht zijn, ziet de code dat de voorraad onder de 150 komt. Dan kan het systeem automatisch een e-mail sturen naar de medewerker die bestellingen doet: “Er moet nieuwe voorraad besteld worden.”
